#Home Accounting

Консольное приложение домашней бухгалтерии на Java: учет доходов, расходов, просмотр баланса

## Возможности
1. Просмотр меню действий
2. Выбор действия
3. Добавление доходов
4. Добавление расходов
5. Возможность посмотреть баланс
6. Возможность выхода

## Стек 
openjdk версии 21.0.13.0.3 

## Запуск
Нужен JDK 17+
``` bash
javac Main.java
java Main
```

## Структура
- `Main.java` - точка входа и логика приложения
- `.gitignore`, `README.md`
